Welcome to Kubra corp idle! 

A little idle game I am working on for my modern web development class to learn the basics of vanilla html, css, and javascript. 

So far the game is simple, choose a resource, and click away to get the chosen resource along with gold on every click. 

At the moment levels are increased with every 10xp just to keep things simple. Everything is pretty simple, for now, but that's because I want a nice foundation for other systems.

Enjoy!
